Interface and Panes

The main file area supports one or two location panes. Split view can be toggled when enabled by the descriptor. Each pane has its own location history, filter/search fields, view mode and preview/metadata presentation.

View modes

List emphasises names, Details shows structured columns, and Icons gives resources a larger row presentation and treats companion .info files as presentation metadata rather than duplicate visible resources.

Panel controls

Toolbar, Operations, Preview, Metadata, Places details and Split View are independent capabilities. Their initial visibility is descriptor-controlled and their runtime visibility can be toggled where exposed.
