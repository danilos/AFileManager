Network Locations

Network locations are integrated through the Location Service. In 0.7.5.8, the ATransfer provider supplies remote location discovery/listing and transfer while AFileManager continues to use the same logical-location APIs used for local resources.

Saved locations

Use the Places network-location actions to add, edit, test or remove saved network entries. Entries are persisted in AFileManager.network-locations.

Current scope

Remote browsing and transfer are available. Remote rename, delete, create-folder and move are not yet exposed as full provider mutations in this version.
