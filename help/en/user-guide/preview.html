Views, Preview and Metadata

The Presentation Service resolves a selected resource through Content, Resources and DataTypes services and chooses an embeddable presentation provider. AFileManager therefore does not hard-code file extensions into the main UI.

Preview

HTML, AmigaGuide and images have dedicated presentation providers. Text resources use the editor-style preview path where applicable. Image presentations provide fit/size/zoom commands. HTML provides Back, Top and zoom commands.

Metadata

Metadata includes basic resource information, DataTypes classification, image dimensions and volume information when relevant. Metadata describes the selected resource, not merely the currently displayed preview.
