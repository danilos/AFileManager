Console, ARexx and Macros

The Console, ARexx and Macro surfaces share the canonical command service used by menus and toolbar controls. Automation therefore dispatches the same command identifiers rather than maintaining a separate implementation of file-manager behaviour.

Console

Choose Console from the Commands operation page, or use Open Console Here on a folder. The interactive console opens as its own document tab beside Files and editable documents. Opening it again reuses the same tab and moves the session to the requested location. Local commands use the platform shell; remote locations expose the supported location-service commands. Command failures and unavailable operations are shown visibly in the console/status instead of being left only in diagnostics.

ARexx

The application exposes the AFILEMANAGER.1 ARexx port. Registered verbs include Refresh, Up, Back, Copy, Paste and Delete.

Command history

Executed command identifiers can be retained in AFileManager.commands according to the descriptor's command-history settings.
