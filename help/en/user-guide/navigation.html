Navigation and Places

Breadcrumbs are the normal location control. Click a breadcrumb to navigate to that level; click the editable area to type a path directly and press Enter to return to breadcrumb mode. Parent navigation is provided by the breadcrumbs and navigation commands, so file lists do not contain a synthetic .. directory row. Standard text-selection/editing behaviour is provided by AROSA text controls.

Places

The Places tree combines assignments, configured groups, favourites, recent locations and saved network locations. The tree is filterable while preserving group ancestry.

Favourites and recents

Folders can be added to or removed from favourites. Favourites and history are persisted next to the application as AFileManager.favorites and AFileManager.history.
