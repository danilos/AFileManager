Using AFileManager

AFileManager can operate as a single-pane or dual-pane manager. The active pane owns selection, navigation and operations; the other pane can be used as a copy/move destination.

Available capabilities

Current capabilities include local file browsing; Places and favourites; recent locations/files; list, details and icon modes; filtering and recursive search; preview and metadata; text editing; image, HTML and AmigaGuide presentation; archive listing/compression/extraction; clipboard operations; reversible operation history; drag and drop; network locations through ATransfer; Console, ARexx and Macro command paths; theme/localization layers; and contextual hints/bubbles.
