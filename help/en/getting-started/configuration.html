Configuration

AFileManager is configured through external window descriptors and one selected user overlay. Version 0.7.56.0.0.0 provides the graphical Configuration dialog built from the shared AROSA dialog and control services.

Descriptors

The supplied descriptors progress from bare and basic layouts through navigation, operations and complete configurations. Descriptor inheritance lets a specialised layout reuse lower-level definitions.

User overlays

The release descriptor loads exactly one user overlay through its [Configuration] section. default.user is the normal full workspace. compact.user, dual-pane.user and full.user are alternative standalone profiles; they are not cumulative and must never be copied over the release descriptor.

The normal startup chain is the optional state selector AFILEMANAGERSTATE:AFileManager.window, otherwise Resources/AFileManager.window, then Resources/descriptors/AFileManager.release.window, with a writable profile override under AFILEMANAGERSTATE:Profiles/ falling back to the package profile in Resources/configurations/.

Common settings

Configuration controls window size, theme and language, visible capabilities, initial pane locations, list/details/icon view mode, preview placement, panel share, hidden files, deletion confirmation, process stack size, diagnostics and Places groups.

Configuration dialog

Open Configuration from the burger menu. Apply changes the current session without writing configuration. Save applies the changes and writes only the active user overlay selected by the release descriptor. The application and release descriptors remain the capability authority and are never rewritten by the dialog.

Diagnostics

The Diagnostics page enables or disables application diagnostic logging and selects one of the existing AROSA levels: Trace, Debug, Info, Warning, Error or Fatal. The descriptor provides the default; the saved user configuration overrides that default. --verbose temporarily requests Debug and --trace temporarily requests Trace for one launch without changing the saved setting.

Default file view

The Configuration dialog can select List, Details or Icons as the default file view. Saving writes the same default to CurrentLocation and SecondaryLocation in the selected user profile.

Startup descriptor and profile

The Startup page selects the descriptor inherited by PROGDIR:AFileManager.window and the one .user profile loaded after it. Saving these selections affects the next launch; it never merges multiple profiles.

Keyboard shortcuts

The Shortcuts page edits the active keyboard map stored in the selected user overlay. Each line uses Key=Command. Use Key=- to disable an inherited descriptor shortcut without modifying the descriptor itself. Apply changes the current session; Save writes the map to the active .user file.
