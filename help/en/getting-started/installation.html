Installation

Runtime layout

The installed executable lives in AROSA:Applications/AFileManager/. Immutable package resources live below Resources/; mutable settings and workspace state live below AFILEMANAGERSTATE: (normally AROSA:State/AFileManager/).

Updating an existing installation

For a program-only update, replace the AFileManager executable in the existing AFileManager drawer and leave its runtime resource folders in place unless the delivery instructions explicitly name replacement resources. Every AROSA delivery package includes a root DELIVERY-INSTRUCTIONS-*.txt file describing exactly what to copy, where to copy it and how to validate that delivery.

Start the application

Run AFileManager normally to load the state startup selector when present, otherwise PROGDIR:Resources/AFileManager.window. A different descriptor may be supplied as the first command-line argument. The optional --trace switch enables trace diagnostics; when it is first, a descriptor may follow it.

Source build

The source tree includes the AROS i386 build profile under scripts/. With the configured Free Pascal 3.3.1/AROS toolchain and AROSA source tree, run bash applications/afilemanager/scripts/build.sh rebuild. A successful build writes build/aros-i386/afilemanager/AFileManager. Follow the delivery's test section before treating the package as installed successfully.
