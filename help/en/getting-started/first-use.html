First Use

The left side of the main window contains Places. The central area contains the current file view and, when enabled, a second pane. Preview and metadata may be shown beside or below the browser.

Open a location

Select a Places entry, use a breadcrumb segment, or switch the breadcrumb to path editing and type a location. Back, Forward, Up, Home and Refresh use the same navigation service.

Select a resource

Select a file or folder to make it the current resource. File operations act on the active pane. When Preview or Metadata is enabled, the selected resource is presented there.

Open Help

Choose Help from the menu or press F1. Help is loaded from external HTML documentation and rendered by the same AROSA presentation system used by resource previews.
