About AFileManager

AFileManager 0.7.5.8 is the AROSA file-management application built on the AROSA service and retained-UI architecture.

Its design goal is to make file management a consumer of shared AROSA capabilities: paths, resources, locations, content, presentation, metadata, clipboard, reversible operations, shell integration, localization, themes and automation.

Help system

This help is not embedded in the executable. It is a localized external documentation tree ordered by navigation.order files and rendered by the shared HTML Presentation Service, following the same mechanism used by AIDEa documentation.
