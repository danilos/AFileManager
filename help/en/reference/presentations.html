Supported Presentation Types

The current Presentation Service registers providers for AmigaGuide, HTML and images, plus a diagnostic probe fallback. Text editing/preview uses the AROSA editor path.

HTML

Local documentation-style HTML is rendered in-process. Local relative HTML links and anchors are supported. HTTP, HTTPS, FTP, mail and JavaScript schemes are deliberately not followed by the preview/help renderer.

Images

Image presentation supports common image resources recognised by the image/DataTypes services, with fitting and zoom commands.

AmigaGuide

AmigaGuide is adapted into the presentation layer so it can be viewed through the same embeddable document mechanism.
