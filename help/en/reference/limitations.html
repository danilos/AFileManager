Current Limitations

The following are known scope limits of AFileManager 0.7.5.8 rather than hidden features.

  • No graphical Configuration dialog yet; configuration remains descriptor/user-file driven.
  • About and Help are now documentation-system topics; richer common AROSA dialog integration can follow.
  • Remote provider mutation is incomplete: remote rename/delete/create/move are not fully exposed.
  • The content cache currently uses the existing bounded/session behaviour; configurable cache limits and formal LRU replacement are planned.
  • HTML/CSS rendering is adequate for controlled documentation pages but is not yet a modern browser engine.
  • Font rendering and TrueType support are still being expanded in the AROSA Font Service.
