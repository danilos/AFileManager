# Toolbar descriptions
afilemanager_desc_toolbar_details=Shows columns for type, name, size, date and permissions. Applies to the active pane.
afilemanager_desc_toolbar_hidden=Shows or hides files and folders marked as hidden. The setting applies to both panes.
afilemanager_desc_toolbar_icons=Shows items as a grid of icons. Applies to the active pane.
afilemanager_desc_toolbar_list=Lists names only, in compact rows. Applies to the active pane.
afilemanager_desc_toolbar_metadata=Shows the Metadata page of the panel: size, dates, type and datatype details of the selected item. It can be open together with the Preview page.
afilemanager_desc_toolbar_preview=Shows the Preview page of the panel: images, text, HTML, AmigaGuide and archive contents of the selected item. It can be open together with the Metadata page.
afilemanager_desc_toolbar_redo=Applies the last undone file operation again. It is refused if the destination is now occupied.
afilemanager_desc_toolbar_split=Shows a second location pane beside the first, for copying and comparing between two folders.
afilemanager_desc_toolbar_thumbnails=Shows compact preview renditions where the selected resource can provide one.
afilemanager_desc_toolbar_undo=Reverses the last file operation. Nothing is undone if it would overwrite or remove data created since.
